# SILHÉA — Aesthetic Atelier

A minimalist, interactive 3D aesthetic-care portfolio concept by NEXORGE.

## Experience
13 pages: homepage, collection, REFINE, DEW, VEIL, skin explorer, atelier, approach, consultation, journal, scar-care article, FAQ, and privacy/terms.

Original procedural Three.js packaging, opening caps and dropper, exploded layers, product-specific particle sculptures, drag/keyboard rotation, scroll choreography, CGI editorial portraits, and mobile navigation. Respects reduced-motion preferences and pauses offscreen rendering.

Consultation is a local brief builder with text download. No information is sent, no appointments are booked, and products are not sold. Saved product choices use sessionStorage.

## Run
Serve this folder using `python3 -m http.server 8085` and open http://localhost:8085.
No build step or remote runtime dependencies.

## Concept and sources
SILHÉA is fictional. Packaging, volumes, and product names are design concepts, not verified formulations. CGI portraits are not patient results. Educational category notes reference GOSH NHS scar-care guidance and American Academy of Dermatology moisturizer guidance, linked within the pages.
